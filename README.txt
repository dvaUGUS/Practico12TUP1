CARRITO DE COMPRAS - PRACTICO12TUP1

Este proyecto consiste en una tienda web interactiva que simula un carrito de compras funcional con catálogo de indumentaria y calzado.
Dicha página web permite al usuario navegar por un catálogo de productos cargados desde un archivo JSON y seleccionar productos,
gestionar las cantidades en el carrito de compras y calcular el importe total del pedido.


DESCRIPCIÓN DE LAS GESTIONES PRINCIPALES:

Catálogo Dinámico: Carga e iteración de productos mediante consumo de un archivo JSON.
Gestión de Carrito: Agregar, incrementar, decrementar y eliminar productos.
Cálculo de Totales: Actualización automática del precio final a pagar.
Persistencia de Datos: Uso de sessionStorage para conservar el carrito al recargar la página.
Interfaz Adaptable: Maquetado responsivo adaptado para escritorio y celulares.

LENGUAJES Y TECNOLOGÍAS UTILIZADOS PARA SU DESARROLLO:

HTML5: Estructura básica de la interfaz de la tienda y su contenido.
CSS: Flexbox y GRID.
JAVASCRIPT: DOM, lógica del carrito y funcionalidades.
JSON: sessionStorage para el stock de productos.
